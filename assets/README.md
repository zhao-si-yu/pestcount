# assets 目录

给合成数据脚本用的素材，**建议只放少量示例，大量素材自行放到本地不提交**。

```
assets/
├── boards/     # 干净的诱捕板背景照片（黄板/蓝板，不同光照各来几张）
└── insects/    # 单只害虫贴图，优先透明底 PNG
```

## 单虫贴图怎么来

1. 从已有的诱捕板照片里，用标注工具或图像编辑软件把单只虫裁出来；
2. 背景不干净的，用抠图工具去掉背景并保存为带 alpha 的 PNG；
3. 每类虫准备 10~30 张不同姿态的贴图，合成多样性就够用了；
4. 没有透明 PNG 也可以直接放普通图，脚本会用 Otsu 阈值把比板面暗的
   区域当作前景自动抠图（适用于黄板粘虫的典型成像）。

## 合成质量提示

* 贴图实际尺寸要和真实照片里的虫体尺寸一致，`--size-range` 按你的
  拍摄距离调，比例错了会学到错误的尺度先验；
* 合成样本用于预训练，最终精度靠少量真实标注微调补上域差距。
